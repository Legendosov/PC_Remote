# PC Remote 🖥️📱

Приложение для управления компьютером с телефона через локальную сеть (Wi-Fi).
Проект состоит из двух частей: Android-приложения и Python-сервера для ПК.

## 🚀 Возможности
- 🔊 Управление системной громкостью и громкостью отдельных приложений (микшер).
- 🚀 Запуск сайтов и программ (ярлыки) на ПК.
- 🔒 Блокировка, спящий режим, перезагрузка и выключение ПК.
- 🎵 Управление медиа-плеером (плей/пауза, следующий трек).
- 🎨 Светлая и темная темы, масштабирование интерфейса.
- 🔔 Уведомление о статусе подключения.

## 🛠️ Технологии
- **Android:** Kotlin, Jetpack Compose, OkHttp, Firebase Auth.
- **PC-сервер:** Python 3.10+, FastAPI, Pycaw (управление звуком), PyAutoGUI (медиа), PyQt5 (GUI).

## ⚙️ Как запустить (Инструкция для ПК)

Так как сервер написан на Python, для его запуска на компьютере **необходимо установить Python и зависимости**. Ниже пошаговая инструкция.

### Шаг 1. Установка Python
1. Скачайте Python версии **3.10 или выше** с официального сайта: [python.org/downloads](https://www.python.org/downloads/).
2. При установке **обязательно** поставьте галочку **«Add Python to PATH»** (в самом низу установщика).

### Шаг 2. Установка библиотек
1. Откройте командную строку (cmd) или терминал в папке с проектом.
2. Выполните команду:
   ```bash
   pip install fastapi uvicorn pycaw pyautogui comtypes qrcode pillow PyQt5
### Шаг 3. Запуск сервера
В той же папке выполните:
     python local_agent_gui.py
### Шаг 4. Подключение телефона
Установите APK-файл (app-release.apk) на телефон.

Убедитесь, что телефон и ПК находятся в одной Wi-Fi сети.

В приложении нажмите «+» и введите IP-адрес, который показывает окно Python.

Готово! Теперь вы можете управлять ПК.
